## Resultado

- **Crash corrigido: textos próprios do fork.**
  - O Time Gate derrubava o jogo (`Message_OpenText` → `memcpy` de nulo, texto `0x9216`). O fork monta esse texto
    e outros por hook C++ `OnOpenText` (`ItemMessages.cpp`, `picto_message.cpp`), que não entram na DLL.
  - Agora as `Message_StartTextbox`/`Message_ContinueTextbox` do código do fork passam por `resource_guard.c`.
    Antes de abrir a caixa, o `text.cpp` grava o texto do id pelo `linkspan.oot.text`, com o estado do momento.
  - Ids cobertos:
    - Time Gate `0x9216`;
    - Lantern `0xF9`, texto pela cor do fogo;
    - Pictobox `0x6F08`;
    - trade MM `0x6F0A`.
  - Nenhum desses ids é aberto pelo código do host.
  - Os textos do Sensor da Slate (`0x9300/0x9301`) o fork só monta com o randomizer ligado; ficam para a NEI-013.
- **Guarda de atores.**
  - Ator de outro dono sem função apontando para a DLL agora sai da tabela.
  - Antes, o Link recriado no mesmo endereço depois de uma troca de cena continuava contado como sobreposto.
  - Continua contado, com razão, o Link que o fork restaura com `Player_Draw`: na DLL esse símbolo é o thunk, e o
    descarregamento o devolve ao ponteiro original.
- **Instrumento:** `eqx_<slate|hourglass|crystal|seasons>` põe os itens de id u16 no C pelo marcador
  `ITEM_EXT_BUTTON` (a tabela do `kaleido_shim.c`), com a posse pelo caminho do get-item do fork.
