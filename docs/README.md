# Link-Span documentation

## Language policy

Modder guides use **English as the main language**: `name.md`, with a complete Brazilian Portuguese sibling `name.pt-BR.md`. The generated Lua API follows the same pairing. Use the language selector at the top of each guide.

Project records (`PLAN`, `AGENTS`, RFCs and `coordination/`) remain in Portuguese, with `.en.md` English translations. The API/architecture documents linked below use English + `.pt-BR.md` pairing. This policy does not turn historical research records into public modder guides.
