# Documentação do Link-Span

## Política de idioma

Guias para modders usam **inglês como idioma principal**: `nome.md`, com irmão completo em português do Brasil `nome.pt-BR.md`. A API Lua gerada usa o mesmo pareamento. Use o seletor de idioma no início de cada guia.

Registros do projeto (`PLAN`, `AGENTS`, RFCs e `coordination/`) continuam em português, com traduções inglesas `.en.md`. Os documentos de API/arquitetura abaixo usam inglês + `.pt-BR.md`. Essa política não transforma pesquisas históricas em guias públicos de modders.
